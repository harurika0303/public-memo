# ADR-0004: 学習記録アプリを NestJS 単一言語で実装し 3 言語展開はしない

## ステータス
承認済み

## 背景

ポートフォリオとして学習記録アプリを追加することが決定した。このアプリをタスク管理 API と同様に3言語で実装するか（合計6本）、あるいは1言語に絞るか（合計4本）を検討した。

タスク管理 API は「同一仕様を3言語で展開する」戦略（ADR-0001）を採用しており、学習記録も同様の戦略をとることは可能だった。

## 決定

**学習記録アプリは NestJS（TypeScript）の1言語のみで実装し、3言語展開はしない。**

NestJS を選んだ理由：タスク管理 API の3番目の実装でもあるため、TypeScript / NestJS のスキルを集中的に証明する場として活用する。

## 代替案

**案 A：学習記録も3言語で実装する（採用せず）**

タスク管理 API と同様に Spring Boot → Laravel → NestJS で学習記録を実装する。合計6本のポートフォリオになる。

- 不採用の理由：週10時間・継続リスクがある中で6本は過剰。実装数より各作品の品質と早期の転職活動開始を優先する

**案 B：別の新言語（Go・Python）で実装する（採用せず）**

Go や Python など、バックエンド3本柱以外の言語で作る。

- 不採用の理由：500万円達成という当面の目標に対して、新言語の追加は投資対効果が低い。Java・PHP・TypeScript の3本柱が確定しているため、軸をぶらさない

## 結果

- タスク管理（Spring Boot・Laravel・NestJS）+ 学習記録（NestJS）の計4本が最終的なポートフォリオ構成になる
- NestJS は2つのアプリで使われるため、TypeScript / NestJS のスキルが最も多く実証される構成になる
- 学習記録アプリは仕様設計の自由度が高い（タスク管理の仕様制約を受けない）ため、独自の設計判断を示せる
