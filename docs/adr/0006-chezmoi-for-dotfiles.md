# ADR-0006: dotfiles 管理ツールとして chezmoi を採用する

## ステータス
承認済み

## 背景
WSL を再インストールする機会に dotfiles を初めて体系的に管理することにした。
管理ツールを選ぶにあたり、以下の制約が存在した：

- 今後 **複数の Windows PC**（会社・自宅）と**将来 Mac** にも同じ dotfiles を適用したい
- dotfiles に不慣れであり、学習コストの低いツールが望ましい
- SSH 秘密鍵・API Token などのシークレットはリポジトリに含めたくない
- ブートストラップは dotfiles の配置だけ自動化できればよい（パッケージは手動可）

## 決定
**chezmoi** を採用する。

`chezmoi init --apply <GitHubリポジトリURL>` の1コマンドで dotfiles を適用できる。
OS ごとのテンプレート（`.chezmoi.toml.tmpl`）で macOS / Linux の差分を吸収できる。
シークレットは `chezmoi secret` コマンドや外部ファイル参照で外出しでき、リポジトリには含めない。

## 代替案

| ツール          | 特徴                             | 採用しなかった理由                                         |
| --------------- | -------------------------------- | ---------------------------------------------------------- |
| GNU Stow        | シンボリックリンク方式・シンプル | OS 差分対応なし・テンプレート機能なし                      |
| yadm            | git ラッパー・導入簡単           | テンプレートは弱い・マルチOS の管理が煩雑になりやすい      |
| bare git        | ツール不要・git のみ             | 初心者に操作ミスのリスクが高い・OS差分管理が手動           |
| 手製 install.sh | 自由度が高い                     | メンテナンスコストが高く、再現性を自前で担保する必要がある |

## 結果

- `~/.local/share/chezmoi/` が dotfiles の管理ディレクトリになる
- 新規マシン（WSL・Mac）への適用は1コマンドで完結する
- macOS 移行時は `os` テンプレート変数で分岐するだけで同一リポジトリを使い回せる
- シークレット（SSH 秘密鍵・.env 等）は chezmoi リポジトリ外で手動管理するため、リポジトリを GitHub Private にしていても漏洩リスクがない
