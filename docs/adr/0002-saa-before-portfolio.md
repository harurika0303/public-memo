# ADR-0002: SAA 取得をポートフォリオ開発より先に行う

## ステータス
承認済み

## 背景

バックエンドエンジニアとして年収 500 万円を目指すにあたり、AWS SAA とポートフォリオ開発の両方が必要と確定している（ADR-0001 参照）。

SAA は現職のランクアップ要件にも含まれており、合格時に報奨金が支給される。また CLF（Cloud Practitioner）を2年前に取得済みのため、SAA へのアップグレードは「ゼロから」ではなく「基礎概念の拡張」として位置づけられる。

週あたりの学習可能時間は 10 時間。SAA とポートフォリオ開発を並行する場合、どちらかに集中する場合に比べて完成・合格がともに遅れるリスクがある。

## 決定

**Phase 1（最初の3ヶ月）を SAA 取得に集中し、ポートフォリオ開発は Phase 2 以降に開始する。**

時間配分：週 7〜8 時間を SAA 学習、残り 2〜3 時間で Spring Boot の基礎復習（ポートフォリオは着手しない）。

## 代替案

**案 A：ポートフォリオを先に作る（採用せず）**

Spring Boot ポートフォリオを先に完成させてから SAA を取得する。

- メリット：転職市場に早くアクセスできる
- 不採用の理由：ポートフォリオに AWS デプロイを含める予定のため、SAA 学習と並行するほうが理解が深まる。また現職の報奨金・ランクアップ動機が先に活かせない

**案 B：SAA とポートフォリオを並行する（採用せず）**

週 5 時間を SAA、5 時間をポートフォリオに分割する。

- メリット：どちらも同時に進む
- 不採用の理由：週 10 時間を分割すると両方が中途半端になるリスクが高い。継続リスク（業務学習に時間を奪われる）が既に存在するため、さらに分散させることは継続困難の原因になると判断した

## 結果

- Phase 1 終了時点（3ヶ月後）に SAA 合格・現職報奨金取得・ランクアップ条件クリアが重なる
- SAA 学習中に得た AWS 知識（EC2・ECS・RDS・VPC）が、Phase 2 のポートフォリオ AWS デプロイに直結する
- 3ヶ月間ポートフォリオの着手が遅れるが、SAA 合格という明確なマイルストーンが継続の動機として機能する
