# Docker Compose — `services.ports` について

> 参考: [公式ドキュメント — Define services in Docker Compose # ports](https://docs.docker.com/reference/compose-file/services/#ports)

---

## 概要

`ports` は、ホストマシンとコンテナ間のポートマッピングを定義します。  
外部からコンテナ内のサービスにアクセスするために使います。

> **注意**: `network_mode: host` と `ports` は同時に使えません。  
> `network_mode: host` はコンテナのポートをホストネットワークに直接公開するため、ポートマッピングは不要です。

---

## 短縮記法（Short syntax）

コロン区切りの文字列で指定します。

```
[HOST:]CONTAINER[/PROTOCOL]
```

- `HOST`: `[IP:](port | range)` — 省略時はすべてのネットワークインターフェース（`0.0.0.0`）にバインド
- `CONTAINER`: コンテナ側のポートまたはポート範囲
- `PROTOCOL`: `tcp` または `udp` — 省略時は `tcp`

```yaml
ports:
  - "3000"              # コンテナポートのみ（ホスト側は自動割り当て）
  - "3000-3005"         # ポート範囲
  - "8000:8000"         # ホスト:コンテナ
  - "9090-9091:8080-8081"
  - "49100:22"
  - "127.0.0.1:8001:8001"     # ループバックにのみバインド
  - "127.0.0.1:5000-5010:5000-5010"
  - "::1:6000:6000"            # IPv6
  - "[::1]:6001:6001"          # IPv6（ブラケット記法）
  - "6060:6060/udp"            # UDP
```

> **警告**: ホスト IP を指定しない場合（例: `"8080:80"`）、Docker はすべてのインターフェース（`0.0.0.0`）にバインドします。  
> ホストに公開 IP がある場合、コンテナがインターネットに直接公開される可能性があります。  
> 必要に応じて `127.0.0.1:8080:80` のように IP を明示してください。

`HOST:CONTAINER` は YAML の base-60 float 解釈との衝突を避けるため、**常に文字列（クォート付き）で書くことを推奨します**。

---

## 詳細記法（Long syntax）

短縮記法では表現できない詳細な設定ができます。

```yaml
ports:
  - name: web
    target: 80
    host_ip: 127.0.0.1
    published: "8080"
    protocol: tcp
    app_protocol: http
    mode: host

  - name: web-secured
    target: 443
    host_ip: 127.0.0.1
    published: "8083-9000"
    protocol: tcp
    app_protocol: https
    mode: host
```

| フィールド     | 説明                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| `target`       | コンテナ側のポート番号                                                                                     |
| `published`    | ホスト側の公開ポート。文字列で指定し、`start-end` の範囲指定も可能                                         |
| `host_ip`      | バインドするホストの IP アドレス。未設定時は `0.0.0.0`                                                     |
| `protocol`     | プロトコル（`tcp` または `udp`）。デフォルトは `tcp`                                                       |
| `app_protocol` | アプリケーションプロトコル（例: `http`, `https`）。Docker Compose 2.26.0 以降                              |
| `mode`         | Swarm での公開方法。`host`（各ノードで公開）または `ingress`（ロードバランシング）。デフォルトは `ingress` |
| `name`         | ポートの用途を示す任意の名前（ドキュメント目的）                                                           |

---

## 短縮記法 vs 詳細記法の使い分け

| ケース                                    | 推奨記法 |
| ----------------------------------------- | -------- |
| シンプルなポートマッピング                | 短縮記法 |
| IP バインドやプロトコルを細かく指定したい | 詳細記法 |
| Swarm での公開モードを設定したい          | 詳細記法 |

---

## まとめ

- `ports` はホスト↔コンテナ間のポートマッピングを定義する
- 短縮記法（`"ホスト:コンテナ"`）と詳細記法（フィールド指定）の 2 種類がある
- ホスト IP を省略すると **`0.0.0.0`（全インターフェース）** にバインドされるため、セキュリティに注意
- `network_mode: host` と同時に使用することはできない
