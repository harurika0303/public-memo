#### ⚠️ 2026年6月1日から料金体系が変わります（Usage-based billing）

> **公式発表**: 2026年4月27日  
> **移行日**: 2026年6月1日

**変更の概要：**
- 「プレミアムリクエスト数（PRU）」が廃止され、**「GitHub AI Credits」** に置き換わる
- クレジットはトークン消費量（入力・出力・キャッシュ）に基づいて消費される
- 各プランには**プラン料金と同額のAIクレジット**が毎月含まれる（Pro: $10、Pro+: $39）
- コード補完・次の編集提案（Next Edit Suggestions）は**クレジット消費なし**（引き続き無制限）
- クレジット切れ後の低コストモデルへのフォールバックは**廃止**
- 追加クレジットの購入が可能
- 年間プラン加入者は、プラン満了まで現行のPRUベース料金体系が続く（ただし6月1日からモデルの乗数が引き上げられる）

**影響のまとめ：**

| 利用スタイル                   | 影響                                            |
| ------------------------------ | ----------------------------------------------- |
| コード補完メイン               | 影響なし（クレジット消費なし）                  |
| チャット・軽量エージェント     | ほぼ影響なし（$10クレジットで十分な場合が多い） |
| 長時間・高頻度エージェント利用 | クレジットが不足する可能性あり。追加購入が必要  |

- **情報源**: https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/

## 4. ローカルLLM環境の費用試算

Ollama や LM Studio などを使ってローカルで LLM を動かす場合、**ランニングコストは実質0円**だが、**GPUへの初期投資**が必要。

### 必要なVRAM量の目安

| モデルサイズ | 必要VRAM（量子化なし） | 必要VRAM（4bit量子化） | 代表モデル                 |
| ------------ | ---------------------- | ---------------------- | -------------------------- |
| 7〜8B        | 14〜16GB               | 4〜6GB                 | Llama3.1 8B, Qwen3.5 8B    |
| 13〜14B      | 26〜28GB               | 8〜10GB                | Qwen3.5 14B, Codestral 14B |
| 27〜32B      | 54〜64GB               | 16〜20GB               | Qwen3.5 27B, GLM-4.7       |
| 70〜72B      | 140GB〜                | 35〜45GB               | Llama3.1 70B, Qwen3.5 72B  |

### GPU価格の目安（2025〜2026年時点）

| GPU                     | VRAM     | 新品価格目安 | 中古価格目安 | 適した用途                  |
| ----------------------- | -------- | ------------ | ------------ | --------------------------- |
| **RTX 4060 Ti 16GB**    | 16GB     | 約6〜7万円   | 約5〜6万円   | 7〜8Bモデルの量子化不要実行 |
| **RTX 4070 Ti (SUPER)** | 12〜16GB | 約8〜12万円  | 約7〜10万円  | 13〜14Bモデル（量子化あり） |
| **RTX 4090**            | 24GB     | 約25〜30万円 | 約18〜22万円 | 最大30Bまで量子化なしで動作 |
| **RTX 3090 (旧世代)**   | 24GB     | −            | 約8〜12万円  | コスパ重視の24GB構成        |
| **2× RTX 3090/4090**    | 48〜72GB | 約36〜60万円 | 約20〜30万円 | 70Bモデル等                 |

### コーディング向けローカルモデル（Ollamaで利用可能）

| モデル            | サイズ     | 特徴                                                    |
| ----------------- | ---------- | ------------------------------------------------------- |
| **Qwen3.5**       | 0.8B〜122B | OSSマルチモーダル、コーディング・推論に強い、日本語対応 |

- **情報源**: https://ollama.com/search

---

### ローカルLLMの損益分岐点試算

例）RTX 3090中古（約10万円）+ Qwen3.5 14B を使用した場合、  
同等のクラウドAPI（Claude Haiku相当）で月6,000円かかるとすると：

$$\text{回収期間} = \frac{100,000\text{円}}{6,000\text{円/月}} \approx 17\text{ヶ月}$$

**17ヶ月以上使い続ければローカルLLMの方が安くなる計算になる**（電気代・PCパーツ除く）。

## 6. 結論・推奨構成

### 🏆 最もコスパが良い構成

#### 1位: **Cline + DeepSeek V4-Flash API**（超コスパ重視）
- **月額**: 数百円〜数千円（使用量による）
- **必要なもの**: VS Code + Cline拡張 + DeepSeek APIキー
- **なぜコスパが良いか**: DeepSeek V4-Flashは同価格帯で最高水準の性能を誇り、1Mトークン出力わずか$0.28。ChatGPTやClaudeに比べて10〜20倍安い
- **注意点**: 中国企業のAPIのため、機密情報や業務コードには注意が必要

#### 2位: **GitHub Copilot Pro**（手軽さ重視）
- **月額**: $10（約1,550円）
- **なぜコスパが良いか**: $10相当のAIクレジット＋無制限インライン補完で定額。設定不要で即使える。学生・教員は無料
- **注意**: 2026年6月以降はAIクレジット消費型に移行。コード補完は引き続き無制限だが、エージェント多用時はクレジットが不足することがある
- **向いている人**: GitHubを使っている開発者全般

#### 3位: **Cursor Pro**（エージェント性能重視）
- **月額**: $20（約3,100円）
- **なぜコスパが良いか**: 最先端モデルへのアクセスと強力なエージェントモードを$20で使える
- **向いている人**: 大規模リファクタリング・新規開発など、エージェント機能を多用する人

#### 長期投資として: **Ollama + RTX 3090 中古 + Cline/Continue**
- **初期費用**: 約10〜15万円
- **ランニングコスト**: 電気代のみ（月1,000〜2,000円）
- **損益分岐**: 約15〜20ヶ月
- **向いている人**: プライバシー重視・長期的に使い続ける人・ネット接続なしで動かしたい人

### まとめ・一言コメント

- **最安で高品質**: `Cline + DeepSeek API` の組み合わせ。ツール無料＋APIが激安。ただし中国企業のAPIのため業務コードの取り扱いは慎重に。
- **手軽さと安定性**: `GitHub Copilot Pro ($10)` が定番。設定不要で今日から使える。
- **エージェント最強コスパ**: `Cursor Pro ($20)` は最先端エージェント機能を月2,000円台で利用可能。
- **ゼロランニングコスト**: `Ollama + ローカルモデル` は初期投資後は維持費最小。中〜長期利用なら元が取れる。
