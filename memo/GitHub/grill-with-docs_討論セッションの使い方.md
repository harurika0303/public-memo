# GitHub Copilot で討論セッションを始める方法（grill-with-docs）

## 概要

`/grill-with-docs` コマンドを使うと、GitHub Copilot が指定したテーマについて**1問ずつ徹底的に問い詰める**討論セッションを開始します。設計の曖昧さをつぶし、用語を整理し、ドキュメント（`CONTEXT.md` や ADR）をリアルタイムで更新していきます。

---

## 使い方

### 基本

Copilot Chat に以下のように入力するだけです：

```
/grill-with-docs 注文管理システムの設計
```

```
/grill-with-docs 在庫引当ロジックのトレードオフ
```

```
/grill-with-docs MRPの所要量計算の仕様
```

### 入力のコツ

| 良い例                       | 説明                                 |
| ---------------------------- | ------------------------------------ |
| `設計案を文章で貼り付ける`   | 具体的な内容があるほど鋭い質問が来る |
| `迷っている選択肢を書く`     | トレードオフの深掘りをしてくれる     |
| `既存コードの動作を説明する` | コードとの矛盾を検出してくれる       |

---

## セッション中に何が起きるか

1. **コードベースを自動調査** — 関連するコードを先に読んで矛盾を探す
2. **1問ずつ質問** — 各質問に推奨回答付き。回答するたびに次の質問が来る
3. **曖昧な言葉を即座に分解** — 「アカウント」「管理」などの過負荷な用語を解体
4. **用語が確定したら CONTEXT.md を即更新** — 用語集として蓄積される
5. **ADR の提案** — 覆しにくい・文脈なしでは不思議・本物のトレードオフ、の3条件を満たすときのみ提案

---

## ドキュメントの更新先

| ファイル             | 内容                                   |
| -------------------- | -------------------------------------- |
| `CONTEXT.md`         | 用語集（実装詳細は書かない純粋な定義） |
| `docs/adr/NNNN-*.md` | アーキテクチャ決定記録                 |

ファイルが存在しない場合は、初めて用語/ADRが確定したタイミングで自動作成されます。

---

## プロンプトファイルの場所

カスタムプロンプトはユーザープロファイルに保存されているため、**全てのワークスペースで `/grill-with-docs` が使えます**。

```
C:\Users\<ユーザー名>\AppData\Roaming\Code\User\prompts\grill-with-docs.prompt.md
```

---

## カスタマイズ

上記ファイルを編集することで動作を変更できます。

- 質問のスタイルを変える
- 特定ドメインの用語集を最初から組み込む
- 出力先ファイルを変更する
