# Laravel のマイグレーション

> 参考:
> - [Database: Migrations — Laravel 12.x](https://laravel.com/docs/12.x/migrations)

---

## マイグレーションとは

マイグレーション（Migration）とは、**データベースのスキーマ（テーブル構造）をコードで管理する仕組み**です。

テーブルの作成・カラムの追加・変更・削除などをPHPファイルとして記述することで、以下が実現できます。

- チーム全員が同じDB構造を再現できる
- Git でスキーマの変更履歴を管理できる
- 本番・開発・テスト環境のスキーマを統一できる
- ロールバック（変更の取り消し）ができる

---

## マイグレーションファイルの場所

```
database/
└── migrations/
    ├── 0001_01_01_000000_create_users_table.php
    ├── 0001_01_01_000001_create_cache_table.php
    └── 0001_01_01_000002_create_jobs_table.php
```

ファイル名は `日時_処理内容.php` の形式で、実行順序は日時順になります。

---

## マイグレーションファイルの構造

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    // マイグレーション実行時（php artisan migrate）
    public function up(): void
    {
        Schema::create('posts', function (Blueprint $table) {
            $table->id();                        // BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY
            $table->string('title');             // VARCHAR(255)
            $table->text('body')->nullable();    // TEXT（NULL許容）
            $table->foreignId('user_id')         // 外部キー
                  ->constrained()
                  ->cascadeOnDelete();
            $table->timestamps();               // created_at, updated_at
        });
    }

    // ロールバック時（php artisan migrate:rollback）
    public function down(): void
    {
        Schema::dropIfExists('posts');
    }
};
```

## 主なカラム定義メソッド

| メソッド                                         | 対応するカラム型               | 説明                                    |
| ------------------------------------------------ | ------------------------------ | --------------------------------------- |
| `$table->id()`                                   | BIGINT UNSIGNED AUTO_INCREMENT | 主キー（`bigIncrements('id')` と同義）  |
| `$table->string('name')`                         | VARCHAR(255)                   | 文字列                                  |
| `$table->text('body')`                           | TEXT                           | 長文テキスト                            |
| `$table->integer('count')`                       | INTEGER                        | 整数                                    |
| `$table->boolean('active')`                      | TINYINT(1)                     | 真偽値                                  |
| `$table->decimal('price', 8, 2)`                 | DECIMAL(8,2)                   | 小数（合計桁数, 小数点以下桁数）        |
| `$table->date('birthday')`                       | DATE                           | 日付                                    |
| `$table->timestamp('sent_at')`                   | TIMESTAMP                      | タイムスタンプ                          |
| `$table->timestamps()`                           | —                              | `created_at` と `updated_at` を一括追加 |
| `$table->softDeletes()`                          | —                              | `deleted_at` を追加（論理削除用）       |
| `$table->foreignId('user_id')`                   | BIGINT UNSIGNED                | 外部キーカラムを追加                    |
| `$table->json('options')`                        | JSON                           | JSON データ                             |
| `$table->enum('status', ['active', 'inactive'])` | ENUM                           | 列挙型                                  |

---

## カラム修飾子

カラム定義にチェーンして追加のオプションを指定できます。

| 修飾子               | 説明                                     |
| -------------------- | ---------------------------------------- |
| `->nullable()`       | NULL を許容する                          |
| `->default('value')` | デフォルト値を設定する                   |
| `->unique()`         | ユニーク制約を追加する                   |
| `->unsigned()`       | UNSIGNED（符号なし整数）にする           |
| `->after('column')`  | 指定カラムの後ろに追加する（MySQL のみ） |
| `->comment('説明')`  | カラムにコメントを付ける                 |

---

## 外部キーの定義

```php
// 方法 1: foreignId を使う（推奨）
$table->foreignId('user_id')->constrained()->cascadeOnDelete();
// → users テーブルの id を参照。削除時に関連レコードも削除

// 方法 2: foreign を使う（テーブル・カラムを明示）
$table->unsignedBigInteger('author_id');
$table->foreign('author_id')->references('id')->on('users');
```

## 主な Artisan コマンド

| コマンド                                | 説明                                        |
| --------------------------------------- | ------------------------------------------- |
| `php artisan make:migration ファイル名` | マイグレーションファイルを生成する          |
| `php artisan migrate`                   | 未実行のマイグレーションをすべて実行する    |
| `php artisan migrate:rollback`          | 直前のバッチのマイグレーションを取り消す    |
| `php artisan migrate:rollback --step=2` | 指定したバッチ数分ロールバックする          |
| `php artisan migrate:reset`             | すべてのマイグレーションをロールバックする  |
| `php artisan migrate:refresh`           | reset → migrate を実行（DB を作り直す）     |
| `php artisan migrate:fresh`             | テーブルをすべて削除して migrate を実行する |
| `php artisan migrate:status`            | 各マイグレーションの実行状況を確認する      |

> `migrate:fresh` はすべてのデータが消えるため、**本番環境では使用しない**。

## マイグレーションファイルの生成

```bash
# テーブル新規作成
php artisan make:migration create_posts_table

# 既存テーブルへのカラム追加
php artisan make:migration add_status_to_posts_table

# --table オプションで対象テーブルを指定
php artisan make:migration add_status_to_posts_table --table=posts

# --create オプションで create 用テンプレートを生成
php artisan make:migration create_posts_table --create=posts
```

---

## バッチ（Batch）の概念

`php artisan migrate` を実行するたびに、その実行グループに**バッチ番号**が付きます。`migrate:rollback` はバッチ単位で取り消しを行います。

```
migrate:status の例：

  Ran?  Migration                             Batch
  Yes   2024_01_01_000000_create_users_table  1
  Yes   2024_06_01_120000_create_posts_table  2  ← rollback するとここが取り消される
  No    2024_12_01_090000_add_status_to_posts  -
```
