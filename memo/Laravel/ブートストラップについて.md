# Laravel のブートストラップ

> 参考:
> - [Request Lifecycle — Laravel 12.x](https://laravel.com/docs/12.x/lifecycle)

---

## ブートストラップとは

ブートストラップ（Bootstrap）とは、**アプリケーションが動作できる状態になるまでに必要な初期化処理**のことです。

語源は "pull oneself up by one's bootstraps"（ブーツの紐を引っ張って自力で立ち上がる）というフレーズで、「自力で起動する」という概念を表します。コンピュータ全般で「システムが自分自身を初期化・起動するプロセス」を指す言葉として使われています。

---

## Laravel におけるブートストラップの流れ

リクエストが届くと、最初に `public/index.php` が実行され、その中でブートストラップが行われます。

```
1. public/index.php
   └── Composer のオートローダー読み込み
   └── bootstrap/app.php を読み込む

2. bootstrap/app.php
   └── サービスコンテナ（Application インスタンス）を生成
   └── HTTP Kernel・Console Kernel・例外ハンドラを登録

3. HTTP Kernel のブートストラップ
   └── 以下のブートストラッパーを順番に実行
       ├── 環境設定の読み込み（.env）
       ├── 設定ファイルの読み込み（config/）
       ├── 例外ハンドリングの設定
       ├── ファサードの登録（DB::, Cache:: など）
       └── サービスプロバイダの登録・起動

4. ルーター
   └── リクエストをコントローラ / クロージャにディスパッチ
```

---

## ブートストラッパーの役割

HTTP Kernel が実行するブートストラッパーは `Illuminate\Foundation\Http\Kernel` に定義されており、以下を順番に処理します。

| ブートストラッパー         | 役割                                                      |
| -------------------------- | --------------------------------------------------------- |
| `LoadEnvironmentVariables` | `.env` ファイルを読み込み、環境変数を設定する             |
| `LoadConfiguration`        | `config/` 以下の設定ファイルをすべて読み込む              |
| `HandleExceptions`         | エラーハンドリング・例外処理を設定する                    |
| `RegisterFacades`          | `DB::`, `Cache::` などのファサードを登録する              |
| `RegisterProviders`        | `config/app.php` に列挙されたサービスプロバイダを登録する |
| `BootProviders`            | 登録済みのサービスプロバイダをすべて起動（boot）する      |

---

## bootstrap/ ディレクトリ

プロジェクトルートの `bootstrap/` ディレクトリがブートストラップ関連のファイルを格納しています。

```
bootstrap/
├── app.php        ← アプリケーション（サービスコンテナ）の生成と基本バインディング
├── providers.php  ← サービスプロバイダの一覧（Laravel 11 以降）
└── cache/         ← ルート・サービスのキャッシュファイル（自動生成）
    ├── config.php
    ├── routes-v7.php
    └── services.php
```

> `bootstrap/cache/` 内のファイルは `php artisan config:cache` などのコマンドで生成され、パフォーマンス向上のために使用されます。Git 管理には含めません。

---

## サービスプロバイダとの関係

ブートストラップの中心は**サービスプロバイダ**です。データベース・キュー・認証・ルーティングなど、Laravel の各機能はサービスプロバイダとして実装されており、ブートストラップ時に登録・起動されます。

```
ブートストラップ
    ↓
サービスプロバイダの register()  ← サービスコンテナへのバインディング登録
    ↓
サービスプロバイダの boot()      ← 機能の起動（ルート登録・イベントリスナー設定など）
    ↓
アプリケーション使用可能な状態
```
