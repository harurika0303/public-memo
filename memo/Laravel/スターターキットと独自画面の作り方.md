# スターターキットと独自画面の作り方

> 参考:
> - [Laravel Breeze — Laravel 12.x](https://laravel.com/docs/12.x/starter-kits#laravel-breeze)
> - [Laravel Jetstream](https://jetstream.laravel.com/)
> - [Blade Templates — Laravel 12.x](https://laravel.com/docs/12.x/blade)

---

## スターターキットとは

Laravel プロジェクトに**認証機能一式をまるごと追加するパッケージ**です。ログイン・新規登録・パスワードリセット・メール確認などのルート・コントローラ・ビューがすべて生成された状態で開発を始められます。

```bash
laravel new myapp
# インタラクティブに選択肢が表示される
# → スターターキットの選択: Breeze / Jetstream / なし
# → フロントエンドの選択: Blade / Livewire / Inertia(React) / Inertia(Vue)
```

---

## Breeze と Jetstream の違い

|                | **Laravel Breeze**                             | **Laravel Jetstream**                  |
| -------------- | ---------------------------------------------- | -------------------------------------- |
| 向いている規模 | 小〜中規模・学習用                             | 中〜大規模                             |
| 認証           | ログイン・登録・パスワードリセット・メール確認 | Breeze の内容 + 2要素認証              |
| 追加機能       | なし                                           | チーム管理・APIトークン管理（Sanctum） |
| フロントエンド | Blade, Livewire, Inertia/React, Inertia/Vue    | Livewire, Inertia/Vue                  |
| コードの量     | 少なく読みやすい                               | 多機能だが複雑                         |

**学習・個人開発では Breeze から始めるのが定番です。**

## Breeze が生成するもの

`php artisan breeze:install blade` を実行すると以下が生成されます。

```
app/
├── Http/
│   ├── Controllers/Auth/
│   │   ├── AuthenticatedSessionController.php   ← ログイン・ログアウト
│   │   ├── RegisteredUserController.php         ← 新規登録
│   │   ├── PasswordResetLinkController.php      ← パスワードリセットリンク送信
│   │   ├── NewPasswordController.php            ← パスワード再設定
│   │   ├── EmailVerificationController.php      ← メール確認
│   │   └── ConfirmablePasswordController.php    ← パスワード確認
│   └── Requests/Auth/
│       └── LoginRequest.php                     ← ログインのバリデーション

resources/views/
├── auth/
│   ├── login.blade.php                          ← ログイン画面
│   ├── register.blade.php                       ← 新規登録画面
│   ├── forgot-password.blade.php                ← パスワードリセット申請
│   ├── reset-password.blade.php                 ← パスワード再設定
│   └── verify-email.blade.php                   ← メール確認案内
├── layouts/
│   ├── app.blade.php                            ← 認証済みユーザー向けレイアウト
│   ├── guest.blade.php                          ← 未認証ユーザー向けレイアウト
│   └── navigation.blade.php                     ← ナビゲーションバー
├── components/                                  ← 再利用可能な UI パーツ
│   ├── input-label.blade.php
│   ├── text-input.blade.php
│   ├── primary-button.blade.php
│   └── ...
└── dashboard.blade.php                          ← ログイン後のダッシュボード

routes/
└── auth.php                                     ← 認証関連のルート定義
```

これらは**すべて自分で編集可能なファイル**として生成されます（パッケージの内部に隠れているわけではない）。

## 独自画面の作り方

Breeze が用意したレイアウトを継承しながら独自画面を追加していきます。

### 全体フロー

```
① php artisan make:model Post -mrc でひな形生成
        ↓
② マイグレーションにカラムを追加 → php artisan migrate
        ↓
③ routes/web.php にルートを登録
        ↓
④ コントローラに処理を書く
        ↓
⑤ ビュー（Blade ファイル）を作成する
```

---

### ① レイアウトを継承してビューを作る

Breeze が生成した `layouts/app.blade.php` をレイアウトとして使います。

```php
{{-- resources/views/posts/index.blade.php --}}

<x-app-layout>                          {{-- layouts/app.blade.php を継承 --}}
    <x-slot name="header">
        <h2>投稿一覧</h2>
    </x-slot>

    <div class="py-12">
        <div class="max-w-7xl mx-auto sm:px-6 lg:px-8">

            <a href="{{ route('posts.create') }}">新規作成</a>

            @foreach ($posts as $post)
                <div>
                    <a href="{{ route('posts.show', $post) }}">
                        {{ $post->title }}
                    </a>
                </div>
            @endforeach

            {{ $posts->links() }}  {{-- ページネーション --}}

        </div>
    </div>
</x-app-layout>
```

`<x-app-layout>` と書くだけでナビゲーションバー・フッターを含む共通レイアウトが適用されます。

---

### ② フォームの作り方

```php
{{-- resources/views/posts/create.blade.php --}}

<x-app-layout>
    <x-slot name="header">
        <h2>新規投稿</h2>
    </x-slot>

    <div class="py-12">
        <form method="POST" action="{{ route('posts.store') }}">
            @csrf  {{-- CSRF トークン（必須）--}}

            <div>
                <x-input-label for="title" value="タイトル" />
                <x-text-input id="title" name="title" type="text"
                    value="{{ old('title') }}" />
                <x-input-error :messages="$errors->get('title')" />
                {{-- バリデーションエラーを表示 --}}
            </div>

            <div>
                <x-input-label for="body" value="本文" />
                <textarea id="body" name="body">{{ old('body') }}</textarea>
                <x-input-error :messages="$errors->get('body')" />
            </div>

            <x-primary-button>保存</x-primary-button>
        </form>
    </div>
</x-app-layout>
```

`<x-input-label>`, `<x-text-input>`, `<x-primary-button>` は Breeze が生成した `resources/views/components/` の UI パーツです。そのまま流用できます。

---

### Blade の主な構文

| 構文                             | 説明                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| `{{ $変数 }}`                    | 値を HTML エスケープして出力                               |
| `{!! $変数 !!}`                  | HTML エスケープせずに出力（XSS 注意）                      |
| `@if / @elseif / @else / @endif` | 条件分岐                                                   |
| `@foreach / @endforeach`         | ループ                                                     |
| `@csrf`                          | CSRF トークンの hidden input を生成（POST フォームに必須） |
| `@method('PUT')`                 | `PUT` / `DELETE` などの疑似メソッドを指定                  |
| `@auth / @guest`                 | ログイン状態による出力切り替え                             |
| `@error('field')`                | バリデーションエラーメッセージの表示                       |
| `<x-コンポーネント名>`           | `components/` のBladeコンポーネントを呼び出す              |

## まとめ: 担当範囲の整理

```
Breeze が用意するもの
  ├── 認証画面一式（ログイン・登録・パスワードリセットなど）
  ├── 共通レイアウト（layouts/app.blade.php）
  └── 再利用可能な UI パーツ（components/）

自分で作るもの
  ├── 独自機能のモデル・コントローラ・マイグレーション（make:model で生成）
  ├── routes/web.php へのルート登録
  └── 独自画面の Blade ファイル（Breeze のレイアウト・コンポーネントを流用）
```
