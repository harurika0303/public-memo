## 8. 変更管理方針

| 項目                                     | 内容                                            |
| ---------------------------------------- | ----------------------------------------------- |
| 変更の申請方法                           | 変更要求票（CR票）を発行して書面で申請する      |
| 軽微な変更（工数3人日以内）              | PM判断でメール承認                              |
| 重要な変更（工数3人日超 / スコープ影響） | PO・PM・ベンダー三者で書面承認                  |
| 本文書の更新                             | 承認された変更はWBSを更新し、バージョンを上げる |
