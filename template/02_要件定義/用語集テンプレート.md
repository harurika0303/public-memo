# 用語集（業務用語・システム用語）

> **目的：** 開発者とユーザーが異なる言葉を使うことによる認識のズレを防ぐ。プロジェクト開始時に作成し、ヒアリング・設計・開発を通じて継続的に更新する。
> **使い方：** 用語が出てきたら随時追記する。チーム全員がアクセスできる場所に置くこと。

## システム用語（開発者が使う言葉）

> 要件定義書・設計書・ソースコード内で使うシステム的な用語を定義する。ユーザーへの説明時の対応業務用語も記載する。

| 用語（システム） | 対応する業務用語 | 説明・定義                       | 使用箇所               |
| ---------------- | ---------------- | -------------------------------- | ---------------------- |
| ユーザー（User） | 利用者 / 社員    | システムにログインして操作する人 | 全設計書・ソースコード |
| リソース         |                  |                                  |                        |
| エンドポイント   |                  | APIのURL                         | API定義書              |
| マイグレーション |                  | DBのテーブル構造の変更操作       | DB設計書               |
