# バグ報告票

> **目的：** テスト中・UAT中・本番運用中に発見した不具合を記録・追跡する。テストケース（02）の不具合IDと連携させる。
> **使い方：** バグ1件につき1票作成する。または本ファイルをバグ台帳として1ファイルで管理する。

## 重要度・優先度の定義

| 重要度     | 定義                                                             |
| ---------- | ---------------------------------------------------------------- |
| **致命的** | システムが使用不能、データが破損する、セキュリティ上の重大な欠陥 |
| **重要**   | 主要な業務フローが遂行できない、回避手段がない                   |
| **軽微**   | 業務に支障はないが、表示の崩れや誤字など品質上の問題がある       |

| 優先度 | 定義                                                     |
| ------ | -------------------------------------------------------- |
| **高** | 直ちに修正が必要（テストの続行・リリースをブロックする） |
| **中** | 今スプリント内または次回リリースまでに修正する           |
| **低** | 余裕があるときに修正する（リリース後対応も可）           |
