# 初回ヒアリングシート

> **位置づけ：** プロジェクト開始前の最初のヒアリングで使用する。
> **ゴール：** プロジェクトの全体像を把握し、「何のためにシステムを作るのか」を合意する。詳細な機能要件はこの場では追わない。
> **所要時間の目安：** 60〜90分

## 2. 本日のゴール（冒頭で共有する）

```
□ プロジェクトの背景・目的を理解する
```

## 3. 必ず抑えるポイント

<!-- ここが初回ヒアリングの核心。すべてに回答を得ることを優先する。 -->

| 過去に同様のプロジェクトや検討をしたことがありますか？その結果は？               |            |

| 3位  |            |                                                |

<!-- 「なぜその課題が生じているか」「誰が一番困っているか」を記録する -->

### 3.3 期待する成果・成功の定義

| 質問                                                                           | 回答・メモ |
| ------------------------------------------------------------------------------ | ---------- |
| このシステムが完成したとき、何が変わっていれば成功といえますか？               |            |
