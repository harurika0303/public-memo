## 3. データマッピング定義

### 3.1 ユーザーマスタ

| 移行元                    |             | 移行先                 |              | 変換ルール                                 |
| ------------------------- | ----------- | ---------------------- | ------------ | ------------------------------------------ |
| **テーブル / ファイル名** | 旧DB: users | **テーブル名**         | users        |                                            |
| **カラム名（移行元）**    | **型**      | **カラム名（移行先）** | **型**       | **変換・クレンジングルール**               |
| id                        | INT         | —                      | —            | 新IDを採番するため移行しない               |
| user_name                 | VARCHAR     | name                   | VARCHAR(100) | そのまま                                   |
| mail_address              | VARCHAR     | email                  | VARCHAR(255) | 小文字に統一                               |
| passwd                    | VARCHAR     | password_hash          | VARCHAR(255) | 移行しない（初回ログイン時に再設定を促す） |
| user_type                 | CHAR(1)     | role                   | ENUM         | '1'→'admin', '2'→'manager', '3'→'user'     |
| regist_date               | DATETIME    | created_at             | TIMESTAMP    | 値をそのまま移行。タイムゾーンをJSTに変換  |

## 4. データクレンジング方針

| #   | 問題パターン                      | 対応方針                                                              | 担当       |
| --- | --------------------------------- | --------------------------------------------------------------------- | ---------- |
| 1   | NULL・空文字が入っている必須項目  | デフォルト値（〇〇）を設定する / 移行対象外として除外し一覧を報告する | 開発担当   |
| 2   | 重複データ                        | 最新の更新日時のレコードを優先して採用する                            | 開発担当   |
| 3   | 文字コードの不整合（Shift-JIS等） | UTF-8に変換して移行する                                               | 開発担当   |
| 4   | 日付フォーマットの不整合          | YYYY-MM-DD形式に統一する                                              | 開発担当   |
| 5   | 〇〇の値が不正                    | 業務担当者に確認し、修正値を確定してから移行する                      | 業務担当者 |

## 7. ロールバック方針

| 条件                             | 対応                                                 |
| -------------------------------- | ---------------------------------------------------- |
| 移行中にエラーが発生した場合     | 作業を中断し、移行前バックアップからリストアする     |
| 移行後確認でエラーが判明した場合 | バックアップからリストアし、原因を調査して再移行する |

**ロールバック所要時間の見積もり：** 〇〇分
