# インターフェース仕様書（外部連携）

> **目的：** 自システムと外部システム（他社API・SaaS・他部門システム等）の連携仕様を定義する。
> **対象：** 自システムが呼び出す外部API、および外部から自システムのAPIを呼び出すケース両方を記載する。

### IF-001：〇〇社 在庫管理システム — 在庫取得API

#### 基本情報

| 項目                     | 内容                                 |
| ------------------------ | ------------------------------------ |
| **IFID**                 | IF-001                               |
| **連携方向**             | 自システム → 〇〇社在庫管理システム  |
| **方式**                 | REST API / HTTPS                     |
| **認証方式**             | APIキー（HTTPヘッダー `X-Api-Key`）  |
| **本番エンドポイント**   | `https://api.〇〇.co.jp/v1/`         |
| **テストエンドポイント** | `https://api-stg.〇〇.co.jp/v1/`     |
| **呼び出しタイミング**   | 商品詳細画面の表示時（リアルタイム） |
| **タイムアウト**         | 5秒                                  |
| **リトライ**             | 3回（500ms間隔）                     |
| **SLA / 利用制限**       | 〇〇req/min                          |

#### リクエスト

```
GET /v1/stock/{product_code}
```

**ヘッダー：**

| ヘッダー名  | 値                 | 必須 |
| ----------- | ------------------ | ---- |
| `X-Api-Key` | `{APIキー}`        | ○    |
| `Accept`    | `application/json` | ○    |

**パスパラメーター：**

| パラメーター   | 型     | 必須 | 説明                        |
| -------------- | ------ | ---- | --------------------------- |
| `product_code` | string | ○    | 商品コード（例: `ABC-001`） |

#### レスポンス（正常）

```json
{
  "product_code": "ABC-001",
  "stock_quantity": 50,
  "last_updated": "2026-05-10T10:00:00+09:00"
}
```

| フィールド       | 型               | 説明         |
| ---------------- | ---------------- | ------------ |
| `product_code`   | string           | 商品コード   |
| `stock_quantity` | integer          | 在庫数       |
| `last_updated`   | string (ISO8601) | 最終更新日時 |

#### エラーレスポンス

| HTTPステータス | エラーコード           | 意味               | 自システムの対応                                   |
| -------------- | ---------------------- | ------------------ | -------------------------------------------------- |
| 400            | `INVALID_PRODUCT_CODE` | 商品コードが不正   | ログ出力・画面に「在庫情報が取得できません」と表示 |
| 401            | `UNAUTHORIZED`         | 認証失敗           | アラート通知                                       |
| 404            | `NOT_FOUND`            | 商品が存在しない   | 在庫数0として扱う                                  |
| 429            | `TOO_MANY_REQUESTS`    | レート制限超過     | リトライ（60秒後）                                 |
| 500            | `INTERNAL_ERROR`       | 相手システムエラー | リトライ（500ms × 3回）後、ログ出力                |

### IF-002：SendGrid — メール送信

#### 基本情報

| 項目                   | 内容                                              |
| ---------------------- | ------------------------------------------------- |
| **IFID**               | IF-002                                            |
| **連携方向**           | 自システム → SendGrid                             |
| **方式**               | REST API / HTTPS                                  |
| **認証方式**           | Bearer Token（`Authorization: Bearer {API_KEY}`） |
| **エンドポイント**     | `https://api.sendgrid.com/v3/mail/send`           |
| **呼び出しタイミング** | ユーザー登録完了時・パスワードリセット時          |

#### リクエスト概要

```
POST https://api.sendgrid.com/v3/mail/send
```

**送信パターン一覧：**

| テンプレートID                       | 用途                     | 送信タイミング     |
| ------------------------------------ | ------------------------ | ------------------ |
| `d-〇〇〇〇〇〇〇〇〇〇〇〇〇〇〇〇` | ユーザー登録完了メール   | ユーザー登録完了時 |
| `d-〇〇〇〇〇〇〇〇〇〇〇〇〇〇〇〇` | パスワードリセットメール | リセット申請時     |

### IF-003：〇〇基幹システム — CSV連携（受信）

#### 基本情報

| 項目                 | 内容                               |
| -------------------- | ---------------------------------- |
| **IFID**             | IF-003                             |
| **連携方向**         | 〇〇基幹システム → 自システム      |
| **方式**             | CSVファイル（SFTP経由）            |
| **実行タイミング**   | 毎日 01:00（基幹システム側が配置） |
| **受信ディレクトリ** | `/data/import/sales/`              |
| **処理バッチ**       | BAT-002（02:00実行）               |

#### CSVフォーマット

- 文字コード: UTF-8（BOMなし）
- 区切り文字: カンマ（`,`）
- 改行コード: LF
- ヘッダー行: あり（1行目）
- ファイル名規則: `sales_YYYYMMDD.csv`

| 列番号 | 列名           | 型                  | 必須 | 例           | 備考        |
| ------ | -------------- | ------------------- | ---- | ------------ | ----------- |
| 1      | `sale_date`    | string (YYYY-MM-DD) | ○    | `2026-05-10` |             |
| 2      | `product_code` | string              | ○    | `ABC-001`    |             |
| 3      | `quantity`     | integer             | ○    | `100`        |             |
| 4      | `amount`       | decimal             | ○    | `98000.00`   | 税込金額    |
| 5      | `note`         | string              |      | `特注品`     | 最大200文字 |

#### エラー処理

| 状況                               | 対応                                           |
| ---------------------------------- | ---------------------------------------------- |
| ファイルが配置されていない         | アラート通知・スキップ                         |
| フォーマット不正の行がある         | 該当行をスキップしてログ出力・正常行は処理続行 |
| 重複データ（同日ファイルの再配置） | 既存データを上書きする                         |
