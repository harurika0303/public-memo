## 1. ログイン・ログアウト

### 1.1 ログイン方法

1. ブラウザで `https://〇〇.〇〇.co.jp` を開く
2. **メールアドレス** に会社のメールアドレスを入力する
3. **パスワード** を入力する
4. 「**ログイン**」ボタンをクリックする

> **初回ログインの場合：** 管理者から届いたメールの「パスワードを設定する」リンクをクリックし、パスワードを設定してからログインしてください。

**うまくログインできない場合：**

| 症状                                                             | 対処法                                                         |
| ---------------------------------------------------------------- | -------------------------------------------------------------- |
| 「メールアドレスまたはパスワードが正しくありません」と表示される | メールアドレスとパスワードを確認してください                   |
| パスワードを忘れた                                               | ログイン画面の「パスワードをお忘れの方」をクリックしてください |
| 「アカウントがロックされています」と表示される                   | 〇分後に再試行するか、管理者に連絡してください                 |

### 1.2 ログアウト方法

1. 画面右上のユーザー名をクリックする
2. 「**ログアウト**」をクリックする

> ブラウザを閉じるだけではログアウトされません。席を離れるときは必ずログアウトしてください。

## 4. よくある質問（FAQ）

**Q. ログインできません**
→ メールアドレスとパスワードを確認してください。パスワードを忘れた場合はログイン画面の「パスワードをお忘れの方」から再設定できます。

**Q. データが保存されません**
→ 必須項目（赤い「※」マークがついた項目）がすべて入力されているか確認してください。エラーメッセージが表示されている場合は内容を修正してください。

**Q. 画面が正しく表示されません**
→ ブラウザのキャッシュをクリアするか（Ctrl + Shift + Delete）、推奨ブラウザ（Chrome / Edge 最新版）をお使いください。

**Q. 〇〇の操作方法が分かりません**
→ 本マニュアルの〇〇節をご参照ください。それでも解決しない場合はシステム担当者にご連絡ください。
